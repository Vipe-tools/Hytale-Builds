# Hytale Builds

> [!IMPORTANT]
> **This repository is not a programming project.**
> Unlike most repositories on this profile, this repository is a collection of builds created in **Hytale**.

This repository serves as an archive for my Hytale builds.

The builds are exported and stored here so that they can be preserved independently of their original worlds. Some of them were created on older versions of Hytale, so blocks, textures or other parts of a build may look different or no longer work exactly as they originally did.

## Structure

Builds are organized by the Hytale version they were created in.

For example:

```text
Hytale-Builds/
├── Release/
│   ├── Build-Name/
│   │   ├── build.json
│   │   └── README.md
|   |
│   └── Another-Build/
│       ├── build.json
│       └── README.md
│
├── 0.6/
│   └── ...
│
└── README.md
