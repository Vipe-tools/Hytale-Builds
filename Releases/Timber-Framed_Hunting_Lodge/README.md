# Timber-Framed Hunting Lodge
![Size](https://img.shields.io/badge/Size-43×30×53-blue)
![Blocks](https://img.shields.io/badge/Blocks-7%2C729-green)
![Entities](https://img.shields.io/badge/Entities-224-orange)
![Category](https://img.shields.io/badge/Category-Decoration%20Build-purple)
![Creator](https://img.shields.io/badge/Creator-Vipe-lightgrey)

One of my earliest Hytale builds, created around the original release of the game.

The build is a small timber-framed hunting lodge designed for a snowy, forest-like environment. It was built while I was still learning Hytale's building and editor tools and experimenting with the blocks, decorations, and characters available at release.

The lodge includes a fully decorated interior and was designed with particular attention to lighting, both inside and outside, so that the build also works well visually at night.

There is also a small hidden room somewhere in the build that isn't shown in any of the screenshots. Maybe you'll find it. :)
